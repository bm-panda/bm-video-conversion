# 🎬 视频格式转换脚本

一键将视频文件转换为 MP4 / MKV / AVI / MOV / WEBM / GIF / M4V / FLV / WMV / TS 等 10 种格式，基于 FFmpeg 引擎，支持批量处理。

---

## 📖 简介

本工具提供一个简洁的图形配置界面，让您轻松配置转换参数。配置完成后，在文件资源管理器中选中视频文件，右键即可一键完成格式转换。

### ✨ 核心特性

- **10 种格式支持**：基于 FFmpeg 引擎，支持 MP4、MKV、AVI、MOV、WEBM、GIF、M4V、FLV、WMV、TS 互转
- **右键菜单集成**：配置一次，永久生效。选中视频 → 右键 → 一键转换
- **批量处理**：支持同时选中多个视频文件批量转换
- **自定义输出目录**：可指定输出位置，留空则保存到原文件所在目录
- **视频编码器可调**：自动(随格式) / H.264 / H.265(HEVC) / VP9 / MPEG-4
- **分辨率可调**：原始 / 480p / 720p / 1080p（等比缩放，保持宽高比）
- **画质可调**：最佳 / 高 / 标准 / 较低 / 最小（H.264/HEVC/VP9 用 CRF，MPEG-4/WMV 用质量系数）
- **帧率可调**：原始 / 24 / 25 / 30 / 50 / 60 fps
- **音频处理**：保留原音轨 / 重新编码 / 移除音轨
- **智能跳过**：同格式文件、已存在的文件自动跳过（可开启覆盖）
- **元数据保留**：自动保留原文件标题、编码信息等元数据
- **GIF 动画导出**：内置调色板优化，分辨率/帧率自动限幅避免文件过大

## 📦 安装方法

- 通过不忙脚本盒子安装（推荐）
  
  - 下载并安装 [不忙脚本盒子](https://www.bm-box.cn)
  
  - 打开不忙脚本盒子 → **脚本市场** → 搜索 **「视频格式转换」**
  
  - 点击「安装」

- 手动运行（有编程基础用户）
  
  ```bash
  # 1. 安装 FFmpeg（ffmpeg 命令需在 PATH 中可用）
  # https://ffmpeg.org/download.html
  # 2. 配置python环境
  uv venv
  uv sync
  # 3. 启动脚本
  python main.py                # 启动配置界面（无参数）
  python main.py <参数JSON路径>  # 带参数启动（用于右键调用）
  ```

✅ 推荐使用不忙脚本盒子安装、盒子会自动为脚本配置环境、依赖、ffmpeg环境变量、并提供右键、快捷键执行脚本的能力

## 🚀 启动方式

通过不忙脚本盒子安装后，可通过以下方式使用「视频格式转换」功能：

* 配置参数（首次使用或需修改配置时）
  
  * 打开「不忙脚本盒子」
  
  * 点击「视频格式转换」进入配置窗口
  
  * 根据需求设置转换参数
  
  * 点击「保存配置」

* 执行视频格式转换（日常使用）
  
  * 在文件管理器中选中视频文件
  
  * 右键点击，选择「视频格式转换」
  
  * 脚本自动按保存的配置执行格式转换

* 快捷键操作
  
  * 为脚本设置全局快捷键
  
  * 选中视频后按下快捷键即可快速执行

✅ 配置保存后永久生效，无需每次重复设置

🔄 仅在需要更改参数时才需重新进入配置窗口

## 💡 使用提示

- **WEBM / WMV 编码限制**：WEBM 仅支持 VP9 编码，WMV 仅支持 wmv2 编码，选择不兼容的编码器会在转换前提示错误
- **音轨自动兼容**：WEBM / WMV / FLV 等严格容器下选择「保留原音轨」时，若源音轨与容器不兼容（如 AAC 复制进 WebM），会自动降级为重新编码（WebM→Opus、WMV→WMA、FLV→AAC），无需手动干预
- **同格式跳过**：如 mp4 → mp4 会被跳过，如需同容器重编码请改选其他容器或删除已有输出
- **音轨说明**：转换时仅保留第一条音轨，字幕流会被丢弃
